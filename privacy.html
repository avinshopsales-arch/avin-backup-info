دسترسی و هدف

این ابزار خصوصی برای بکاپ فایل‌های مجاز آوین استفاده می‌شود. مجوز Google Drive آن drive.file است: ساخت، خواندن، ویرایش و حذف فایل‌های مرتبط با همین برنامه. این مجوز، دسترسی عمومی به تمام Drive، ایمیل‌ها، مخاطبان یا سابقهٔ مرورگر نمی‌دهد.

نگهداری و حفاظت

محتوای بکاپ پیش از ارسال، با Restic رمزگذاری می‌شود. فایل‌های اتصال در دستگاه‌های مجاز با دسترسی محدود نگهداری می‌شوند. صفحات معرفی، فرم دریافت فایل، تبلیغات و اسکریپت رهگیری ندارند.

حذف یک فایل از منبع، نسخهٔ ثبت‌شدهٔ قبلی را خودکار از تاریخچه حذف نمی‌کند. نگهداری و حذف نسخه‌های بکاپ با سیاست و اقدام مجاز مدیر آوین انجام می‌شود؛ این ابزار برای حذف خودکار تاریخچه تنظیم نشده است.

استفاده و انتقال

داده‌ها برای تبلیغات، فروش اطلاعات یا آموزش مدل‌های عمومی هوش مصنوعی استفاده یا منتقل نمی‌شوند. انتقال لازم برای بکاپ به Google Drive انجام می‌شود. استفاده و انتقال اطلاعات دریافتی از APIهای گوگل تابع Google API Services User Data Policy، از جمله الزامات Limited Use است.

کنترل مالک و تماس

مالک حساب می‌تواند دسترسی برنامه را از اتصال‌های حساب Google لغو کند؛ این کار، انتقال‌های بعدی را متوقف می‌کند و به‌خودی‌خود بکاپ‌های قبلی را حذف نمی‌کند. برای پرسش یا درخواست مرتبط با داده‌ها، با مدیر سامانهٔ آوین تماس بگیرید؛ نشانی پشتیبانی در صفحهٔ رضایت Google نمایش داده می‌شود.

میزبان این صفحات، GitHub Pages، نشانی IP بازدیدکننده را برای امنیت ثبت می‌کند؛ این ثبت مطابق سیاست حریم خصوصی GitHub انجام می‌شود.

Privacy summary

This private AVIN backup utility requests only drive.file, for files associated with the application, not general access to the account's Drive, mail, contacts, or browsing history. Backup content is encrypted by Restic before upload. Connection files are restricted to authorized devices and administrators.

Data is not used or transferred for advertising, sale, or training general-purpose AI models. Transfers necessary for backup are made to Google Drive. Use and transfer of information received from Google APIs comply with the Google API Services User Data Policy, including Limited Use requirements.

Source-file deletion does not automatically erase previously captured backup versions. Authorized AVIN administrators control retention and deletion; automatic history deletion is not configured. Account owners can revoke the app in their Google Account connections. Revocation stops future transfers and does not itself delete existing backups. Contact the AVIN administrator using the support address shown on Google's consent screen. These information pages contain no upload form, advertising, or tracking script. The hosting provider, GitHub Pages, logs visitor IP addresses for security under its privacy policy.
