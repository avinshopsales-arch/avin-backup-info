AVIN FS250 Backup

ابزار خصوصی آوین برای نگهداری نسخه‌های رمزگذاری‌شدهٔ فایل‌ها در Google Drive است. دسترسی آن به فایل‌های مرتبط با همین برنامه محدود می‌شود.

این صفحه فقط برنامه را معرفی می‌کند؛ فرم ورود، کلید اتصال و دسترسی به فایل‌های پشتیبان ندارد. برنامه برای ثبت‌نام عمومی عرضه نشده است.

Private backup utility

AVIN FS250 Backup is a private AVIN utility for encrypted file backups to Google Drive. It uses the limited drive.file permission for files associated with this application.

This information site provides no sign-in, credentials, or access to backup data. The utility is not offered for public registration.
